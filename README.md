# Git & GitHub Learning Repository

A hands-on repository documenting my journey of learning **Git** and **GitHub** from scratch. It contains my notes, command cheatsheets, and practice exercises, written in my own words so that other beginners can follow along.

## Purpose

- Build real, practical experience with Git and GitHub
- Keep clear, searchable notes on every concept I learn
- Share what I learn to help others

## Who is this for?

Anyone starting with version control: students, self-learners, and new developers who want simple explanations and practice tasks.

## Learning Roadmap

- [x] What Git and GitHub are, and how they differ
- [ ] Core terms: repository, branch, commit, clone, push, pull, pull request
- [ ] Creating and cloning repositories
- [ ] add, commit, push, and pull
- [ ] Git configuration and SSH keys
- [ ] Branching and merging
- [ ] Resolving merge conflicts
- [ ] Stash, restore, and reset
- [ ] revert, amend, and reflog (recovering from mistakes)
- [ ] .gitignore, tags, and releases
- [ ] Pull requests, forks, and code review
- [ ] Rebase and cherry-pick
- [ ] GitHub Actions (basic CI)

## Key Concepts

| Term | Meaning |
|------|---------|
| Repository | A project folder tracked by Git, including its full history |
| Branch | A separate line of work inside the same repository |
| Commit | A saved snapshot of your changes |
| Clone | Copy a remote repository to your computer |
| Push | Upload local commits to the remote repository |
| Pull | Download and merge remote changes into your local branch |
| Pull Request | A request to review and merge one branch into another |

## How to Use This Repo

1. Clone it: `git clone https://github.com/[your-username]/git-github-learning.git`
2. Read the notes in `notes/` in order.
3. Try the tasks in `exercises/` in your own practice repo.
4. Open an issue or pull request if you spot a mistake or have a suggestion.
